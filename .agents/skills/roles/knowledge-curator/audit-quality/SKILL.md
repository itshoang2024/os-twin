# audit-quality

## Overview

Audit knowledge namespace quality, coverage, extraction health, and query relevance.

## When to Use

Use this skill when a knowledge-curator workflow needs quality or audit decisions for a namespace.

## Instructions

1. Inspect the namespace state with the Knowledge MCP tools before recommending changes.
2. Prefer reversible, documented actions unless the user explicitly confirms destructive work.
3. Record the rationale, expected impact, and rollback path in the final response.
