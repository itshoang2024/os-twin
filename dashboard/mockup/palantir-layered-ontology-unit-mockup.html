Concept correction

Layers are visual and semantic groupings. They organize Object Type units, but they do not replace the object type model.

TransportationPeopleFinanceEvidence

Object Type Unit

Each row under a layer is a managed ontology unit with identity, properties, source mappings, relationships, validation, and view defaults.

FlightAirportPassengerCrew Member

Palantir-style behavior

The user picks a layer to orient the graph, then selects an Object Type unit to author properties and governed relationship endpoints.

Review: Layer is the container; Object Type is the ontology unit

The sample's left rail is directionally right: Transportation and People are layer groups. The nested items are the units the ontology manages, validates, maps, and publishes. This rewrite makes the distinction explicit in the left rail, graph bands, inspector, and contract mapping.

FE concept changes

  • Layer rows own grouping, visibility, ordering, and view behavior.
  • Object Type rows own identity, properties, source mappings, endpoint rules, and lifecycle.
  • The graph can group by layer while editing a single Object Type unit.

Interaction rule

  • Click a layer to filter or group the graph.
  • Click an Object Type to open the inspector.
  • Drag between Object Type nodes to create a governed relation.
  • Use the matrix to audit endpoint coverage.
